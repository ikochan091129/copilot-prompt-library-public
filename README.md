# Copilot Prompt Library｜運用・版管理

## サイト構成
- `index.html`：PCワークスペースへの入口
- `workspace.html`：エージェント8件・専用98件・汎用40件の横断検索
- `agents.html`：エージェント指示文・説明文・TXT保存
- `general-prompts.html`：汎用プロンプト40件の単独利用と穴埋め入力

## プロンプトの使い分け
- 専用プロンプト：対応するMicrosoft 365 Copilot Agent Builderのエージェントを登録して使う会話用の質問例。指示文との組み合わせが前提。
- 汎用プロンプト：エージェント設定がなくても単体で使うもの。必要な情報を穴埋めして利用する。
- 同じ目的に近い項目は削除せず、本文内の「用途」で使用タイミングを明示する。タイトルはお気に入り・コピー回数の既存キーに使われるため、名称変更前にキー移行設計が必要。

## 安全・公開範囲
この公開リポジトリは一般化した指示文のみを掲載する。会社の非公開資料、実測データ、顧客情報、個人情報、APIキーはGitHub Pagesのフォームや公開リポジトリに入力・保存しない。会社で扱う情報は所属組織で許可された環境のみで扱う。ブラウザの下書き保存にも注意する。

## バージョン管理
- 一覧の`version`・ダウンロード`filename`は現行の統合版を示す。過去の「Ver.1.1本体」「改訂履歴」「共通品質ルール追補」などの版番号は履歴として残し、現行版と区別する。
- 03はVer.1.3（資料構成・不足時対応・禁止事項の強化）を反映。更新後のCopilot Agent Builderには利用者が指示文を再登録する必要がある。
- `agents.html`の`data`と`workspace.html`の`DB.agents`、`agents.html`の`starters`と`workspace.html`の専用98件、`general-prompts.html`の`catalog`と`workspace.html`の汎用40件を改訂時に必ず同期・照合する。
- 両リポジトリで同じ公開用データを反映し、登録件数・本文・旧保存キーとの互換を検証する。

## 年度依存プロンプトの見直し
- 対象：12の「2025年と2026年を比較」「JNCAPの年度差分」を含む、文面に特定の年が記載されたプロンプト。
- 毎年1月および関連する公式NCAPプロトコルの改訂公表時に、対象年・年度、公式文書の適用開始時期・正本、リンク、表記を確認する。
- 年度は暦年と制度上の年度を混同しない。特定年の比較を続ける目的がある場合は元のタイトルを維持してもよい。最新年比較が必要ならユーザーが比較対象の2年度を明示する。
- プロトコル未取得・本文未確認の場合は旧新版の差分を断定しない。
- 自動的な更新・公式サイト監視はこのREADMEでは設定していない。更新は人が確認・承認して実施する。

## ブラウザー保存
- お気に入り・コピー回数の既存キー：`agent-prompt-stats-v1`・`prompt-library-general-v1`。維持する。
- 下書き：`prompt-library-drafts-v1`。タブ内一時保存を基本とし、明示的に選んだ場合のみ同PC内で7日間保存。全削除可能。
