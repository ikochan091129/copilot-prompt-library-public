# Excel｜加速度の台形積分（2チャンネル）

Ver.1.0。汎用のセル参照例。実測値・固有チャンネル名は掲載しない。

## 配置

| 列 | 内容 | 単位 |
|---|---|---|
| TL | 時刻 | ms |
| TM | 加速度A | G |
| TN | 加速度B | G |
| TO | 速度変化A | m/s |
| TP | 速度変化B | m/s |
| TQ | 変位変化A | mm |
| TR | 変位変化B | mm |

40行目が初期データ、41行目から積分する。TO40:TR40に0を入力する。

## 一括貼り付け

TO41を選択し、次の1行（タブ区切り）を貼り付け、TO41:TR41を最終データ行まで下コピーする。

```text
=TO40+(TM40+TM41)/2*9.80665*($TL41-$TL40)/1000	=TP40+(TN40+TN41)/2*9.80665*($TL41-$TL40)/1000	=TQ40+(TO40+TO41)/2*($TL41-$TL40)	=TR40+(TP40+TP41)/2*($TL41-$TL40)
```

## 注意

台形積分。時刻はms、加速度は標準重力加速度を1とするG値。初期速度・変位をゼロとした場合の結果。初期速度が非ゼロなら実際の初期速度を設定する。時刻は数値で単調増加、欠損なしを確認する。符号を保持し、加速度オフセット、重力成分、座標系の回転、フィルタ処理の影響を確認する。回転する局所座標系の成分の単純積分は固定座標系での変位を保証しない。

架空の検算例：一定1G、初期速度0、100ms後の速度0.980665m/s、変位49.03325mm。
